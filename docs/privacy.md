# 나만의 화장실 개인정보처리방침

시행일: 2026-11-09

## 1. 모으는 정보
- **구글 계정 정보**: 로그인할 때 이름과 계정 식별값 (내 화장실을 다른 폰에서 불러오기 위해)
- **내가 저장한 화장실**: 위치(좌표), 건물·층·위치 설명, 비밀번호, 메모
- **공중화장실 메모·평가·사용불가 신고**: 작성 내용, 작성 시각, 작성자 이름
- **위치 정보**: 앱을 쓰는 동안 지도에 내 위치를 보여 주는 데만 쓰며, 서버에 저장하지 않아요

## 2. 쓰는 곳
- 내 화장실 저장·불러오기, 그룹 공유
- 공중화장실 메모·평가·사용불가 표시
- 사용자 수 등 서비스 운영 통계

## 3. 보관 및 삭제
- 앱의 **메뉴 → 계정 삭제**를 누르면 내 화장실, 메모, 평가, 내가 만든 그룹이 바로 지워져요.
- 로그인하지 않으면 내 화장실은 내 폰에만 저장돼요.

## 4. 다른 곳에 주는 정보
- 서버는 Google Firebase를 쓰고, 지도는 카카오맵을 써요. 그 밖에 개인정보를 다른 곳에 팔거나 주지 않아요.
