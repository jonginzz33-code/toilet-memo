# 나만의 화장실 개인정보처리방침

시행일: 2026-11-10

## 1. 수집 항목과 목적
| 항목 | 목적 |
|---|---|
| 구글 계정 이름·식별값 (로그인 시) | 내 화장실 저장·불러오기, 그룹 공유 |
| 내가 저장한 화장실 (위치, 설명, 비밀번호, 메모) | 화장실 기록 서비스 제공 |
| 메모·평가·사용불가 신고·다녀왔어요 (작성자 이름, 시각) | 다른 사용자에게 화장실 상태 안내 |

- 로그인하지 않으면 내 화장실은 내 폰에만 저장돼요.
- 제휴 가게 통계(노출·길찾기 횟수 등)는 누구인지 알 수 없는 횟수만 모아요.

## 2. 위치 정보
- 지도에 내 위치를 보여 주고, 가까운 화장실·길찾기·건물 이름 추천에만 써요.
- 내 위치는 서버에 저장하지 않아요.

## 3. 보관과 파기
- 회원 탈퇴(**메뉴 → 계정 삭제**) 즉시 내 화장실, 메모, 평가, 내가 만든 그룹을 지워요.
- 법령에 따로 보관 의무가 있는 경우 그 기간 동안만 보관해요.

## 4. 처리 위탁·외부 전송
개인정보를 팔거나 다른 곳에 주지 않아요. 서비스 운영을 위해 아래 업체를 이용해요.

| 업체 | 하는 일 | 보내는 정보 |
|---|---|---|
| Google (Firebase) | 로그인, 데이터 저장 | 계정 정보, 저장한 화장실·메모 |
| 카카오 | 지도, 주소·건물 이름 찾기, 길 안내 | 지도 위치, 화장실 위치 |
| OpenStreetMap 길찾기 (routing.openstreetmap.de) | 길찾기 경로 계산 | 출발·도착 위치 (저장 안 함) |

Firebase 서버는 해외(미국 등)에 있을 수 있어요.
