# 테스터 안내문 (카톡으로 그대로 붙여넣기)

🚻 「급할 때」 비공개 테스트 참여 부탁드려요!
화장실·주차장·전기차 충전소·약국을 가까운 순으로 바로 찾는 앱이에요.
※ 안드로이드(갤럭시 등) 폰만 설치돼요 (아이폰 ❌)

⚠ 카톡에서 링크를 바로 누르면 로그인이 안 되거나 오류가 나요.
👉 링크를 꾹 눌러 '복사' → 크롬을 열고 → 맨 위 주소창에 붙여 넣기 → 이동
(아래 ①②③ 모두 이렇게 크롬에서 열어 주세요)

① 구글 그룹 가입
https://groups.google.com/g/mytoilet-testers
→ 앱을 설치할 구글 계정으로 로그인한 뒤 [그룹 가입] 누르기
(크롬 오른쪽 위 동그라미 사진에서 계정 확인 · 폰 플레이 스토어와 같은 계정이어야 해요)
※ 조과일지 테스트에 참여하셨던 분은 이미 가입돼 있어서 ①은 건너뛰어도 돼요

② 테스트 참여
https://play.google.com/apps/testing/kr.mytoilet.app
→ [테스터 되기] 누르기
→ '테스터가 되었습니다'가 나오면 성공!

③ 앱 설치
https://play.google.com/store/apps/details?id=kr.mytoilet.app
→ [설치] (이미 있으면 [업데이트])
※ '항목을 찾을 수 없습니다'가 나오면 5~10분 뒤에 다시 해 보세요
→ 앱을 열고 위치 권한은 [허용]을 눌러 주세요

📌 부탁드려요
• 설치 후 14일 동안 지우지 말고, 가끔 한 번씩 켜 주세요 (정식 출시 조건이에요)
• 불편한 점은 앱 메뉴 → 💬 문의하기로 보내 주세요
• 안 되면 화면을 캡처해서 보내 주세요 🙏
