# 플레이스토어 등록 자료 (복사해서 붙여넣기)

## 앱 이름 (30자)
나만의 화장실

## 짧은 설명 (80자)
급할 때 가장 가까운 화장실과 비밀번호를 바로! 내 화장실·그룹 공유·전국 공중화장실 지도

## 자세한 설명 (4000자)
🚻 나만의 화장실 — 급할 때 바로 찾는 화장실 지도

자주 가는 건물 화장실, 비밀번호가 기억 안 날 때 있으셨죠?
나만의 화장실은 내가 다녀온 화장실의 위치·층·비밀번호를 지도에 저장하고, 급할 때 가장 가까운 곳을 바로 알려 줘요.

■ 이런 걸 할 수 있어요
• 내 화장실 저장: 건물 이름·층·위치 설명·비밀번호·메모를 지도에 핀으로 저장
• 건물 이름 자동 추천: 저장할 때 그 자리 건물·1층 가게 이름을 알아서 추천
• 🚨 급해요: 한 번 누르면 가장 가까운 화장실로 차량·도보 길찾기
• 내비처럼 길 안내: 내가 보는 방향으로 지도가 돌아가요
• 전국 공중화장실: 행정안전부 공중화장실 정보 5만여 곳을 지도에 표시
• 그룹 공유: 가족·회사·동호회끼리 화장실을 함께 저장 (방장·부방장 승인제)
• 다녀왔어요: 최근에 다녀온 날짜를 기록해서 "1주 전"처럼 한눈에
• 공중화장실 평가·메모·사용불가 알리기로 서로 정보 나누기
• 홈 화면 위젯: 앱을 열지 않고 가장 가까운 화장실과 비밀번호 확인
• 🤝 제휴 개방화장실: 제휴 가게 화장실과 혜택 쿠폰

■ 안심하고 쓰세요
• 로그인 없이도 쓸 수 있고, 내 화장실은 내 폰에만 저장돼요
• 로그인하면 폰을 바꿔도 그대로 불러와요
• 내 위치는 서버에 저장하지 않아요

문의는 앱 메뉴 → 💬 문의하기로 편하게 남겨 주세요.

# 데이터 보안 양식 답안

- 사용자 데이터를 수집하거나 공유하나요? → **예**
- 전송 중 암호화? → **예** (HTTPS)
- 사용자가 데이터 삭제를 요청할 수 있나요? → **예** (앱 안 계정 삭제 + 위 계정 삭제 URL)

| 데이터 유형 | 수집 | 공유 | 필수/선택 | 목적 |
|---|---|---|---|---|
| 위치 › 정확한 위치 | 예 (서버 저장 안 함, 처리만) | 아니요 | 선택 | 앱 기능 |
| 개인 정보 › 이름 | 예 | 아니요 | 선택 (로그인 시) | 앱 기능, 계정 관리 |
| 개인 정보 › 사용자 ID | 예 | 아니요 | 선택 (로그인 시) | 앱 기능, 계정 관리 |
| 메시지 › 기타 인앱 메시지 (문의) | 예 | 아니요 | 선택 | 고객 지원 |
| 앱 활동 › 기타 사용자 생성 콘텐츠 (화장실 기록·메모·평가) | 예 | 아니요 | 선택 | 앱 기능 |
| 앱 정보 및 성능 › 비정상 종료 로그 | 아니요 (폰에만 저장) | - | - | - |

※ Firebase·카카오는 "서비스 제공업체"로 처리하므로 '공유'에 해당하지 않아요.

# 콘텐츠 등급 설문 답안
- 카테고리: 유틸리티/생산성/커뮤니케이션 외 기타 → "참조, 뉴스 또는 교육용 아님 / 기타"
- 폭력·성적 콘텐츠·욕설·약물·도박: **모두 아니요**
- 사용자 간 소통: **예** (그룹 공유, 공중화장실 메모) — 신고·차단 기능 있음
- 위치 공유: 다른 사용자와 내 위치 공유 **아니요**
- 디지털 상품 구매: **아니요**
