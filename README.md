# 나만의 화장실

화장실 위치를 지도에 표시하고 건물·층·비밀번호를 메모하는 안드로이드 앱.
GitHub Actions(.github/workflows/build.yml)로 APK를 빌드한다.

## v0.1
- 첫 화면 지도 (오픈스트리트맵, 지도 키 필요 없음), 두 손가락 확대·축소 + ＋/－ 버튼, ◎ 내 위치로
- 왼쪽 위에 '내 주변 약 ○m' 표시 (확대할수록 좁아짐)
- 맨 위 '＋ 지금 위치에 화장실 추가' → 가운데 빨간 화장실 표시, 지도를 움직여 자리 맞추고 '이 위치로 정하기'
- 지도 빈 곳을 꾹 눌러도 그 자리에 추가
- 건물 이름·층·위치 설명·비밀번호·메모 저장, 수정·위치 옮기기·삭제
- 화장실 표시: 남녀 그림(🚻) + 아래 이름표(나만 보기)
- 비밀번호 복사 버튼, 비밀번호는 폰 보안 영역 키로 암호화해서 저장
- 목록 버튼: 가까운 순으로 보기, 누르면 그 자리로 이동
- 그룹 공유·공중화장실은 다음 버전 (서버·공공데이터 키 연결 후)

## v0.2
- 패키지명 kr.mytoilet.app (플레이스토어 대비, 출시용 키·키 값은 GitHub 비밀값)
- 지도를 카카오맵으로 교체, 내 위치 따라가기 버튼
- 내 위치 캐릭터: 동글이 (메뉴에서 휴지 친구·물방울이로 바꾸기)
- 화면 가운데 큰 원 + 반경 자동 표시, 원 안 화장실만 보기 (토글)
- 구글 로그인 · 서버 저장 (폰 바꿔도 불러오기) · 그룹 공유(초대 코드)
- 공중화장실 (행정안전부 공중화장실 API), 관리자 버튼 하나로 업데이트
- 공중화장실 상세: 평점 요약(최근 60일), 내 평가, 휴지 없음·고장, 사용자 메모(수정·삭제·신고·차단)
- 사용불가 알리기: 지도에 빨간 표시 + 건수, 24시간 또는 '다시 열렸어요'로 꺼짐
- 관리자 페이지: 사용자 수·접속·메모 수, 서버 사용량, 신고 메모 관리
- 리퀴드 글라스 창, 아래에서 올라오는 창, 토글 스위치, 맨 위 로딩 막대, 프리텐다드 글씨
- 고정 APK 링크(Releases), 내 폰 버전 앱 안 자동 업데이트
- 계정 삭제, 이용약관 동의, 개인정보처리방침

## v0.3
- 카카오 지도 키 연결 (조과일지 카카오 앱 키 함께 사용)
- 지도가 뜨자마자 앱이 꺼지던 문제 고침
- 앱이 꺼지면 다음 실행 때 이유를 보여 줌 (복사 버튼)
- 지도를 축소할수록 캐릭터·화장실 표시도 작아짐

## v0.4
- 🔍 위치 검색 (주소·장소 이름), 화장실 추가·위치 옮기기 중에도 검색 가능
- 화장실 상세 맨 위에 최근 수정 날짜, 지도 표시에 '1주 전' 같은 날짜
- 공중화장실: 전국 데이터를 GitHub가 매달 받아 좌표로 바꿔 두고 앱이 내려받음 (로그인 필요 없음)
- 새 앱 아이콘 (하늘색 집 + 남녀)
- 화장실 추가 때 카카오 지도로 건물 이름·1층 가게(예: 파리바게뜨 건물) 자동 추천
- 나만 보기 화장실 표시를 주황색으로
- 화장실 추가·옮기기 때 큰 빨간 핀 (핀 끝이 저장 자리)
- '＋ 화장실 추가'는 지금 보고 있는 지도 자리에서 시작 (검색한 곳 그대로)
- 가까운 순 목록에 공중화장실(2km 안)도 함께
- 가까운 순 목록은 화면 절반 높이, 안에서 스크롤
- 길찾기: 🚗 차량 / 🚶 도보 나눠서 지도에 길 표시, 카카오맵 안내로 넘기기
- 📁 나의 화장실: 내가 올린 화장실 모음, 줄마다 그룹 공지 스위치
- 지도 색: 나만 보기 주황, 그룹 공유 보라
- 사용불가 신고 목록은 앱을 켤 때만 읽음 (2분마다 읽기 없앰)
- 🚨 급해요: 가장 가까운 화장실(내 것+공중)로 바로 도보 길찾기
- 다녀왔어요: 날짜만 오늘로 서버에 올림 (공중화장실은 모든 사용자에게 '최근 다녀옴' 표시)
- 홈 화면 위젯: 가장 가까운 내 화장실과 비밀번호, ⟳ 새로고침 누를 때만 위치 계산, 길찾기 누르면 차량/도보 고르기

## v0.5
- 뒤로가기: 길찾기 중이면 길 지우기, 추가 중이면 취소, 그 외엔 '앱을 종료할까요?' 확인

## v0.6
- 🤝 제휴 가게(개방화장실): 관리자만 등록·수정·삭제, 모든 사용자 지도에 사진 핀(★)으로 표시
- 등록: 가게 사진, 지도 핀으로 위치, 화장실 위치 설명, 개방 시간, 이용 규칙
- 비밀번호 칸: 번호 입력(매장 50m 안에서만 보이기) 또는 '직원에게 말씀해 주세요'
- 🎁 쿠폰 있음 체크 시 쿠폰 문구·쿠폰 보여 주기 (끄면 안 보임)
- 관리자: 가게별 이번 달 통계 (지도 노출·상세·길찾기·다녀왔어요·쿠폰), 사장님께 보낼 이미지 공유
- 급해요·가까운 순 목록에 제휴 가게 포함
